# 瞳守科技 — 让每一个家，都被温柔注视

一个看起来人畜无害的智能家居营销网站。

直到你开始往下滑。

> ⚠️ **内容警告**：本页面包含突发惊吓（jump scare）、闪烁画面、恐怖音效与逐渐失控的视觉内容。
> 心脏病、光敏性癫痫患者及易受惊吓者请勿体验。建议成年人在心理承受范围内游玩。

## 🎮 怎么玩

- 打开页面后，**像浏览普通购物网站一样慢慢往下滑**就好。
- 🎧 建议：**戴耳机、关灯、慢慢滑**。首次点击页面后环境音会自动响起（右上角可关闭）。
- 终幕锁屏时按 **Esc** 可以逃跑（它会表示失望）。
- 它会记得你是第几次来。

## 🔒 隐私说明

本页面**不会调用摄像头、不会收集或上传任何数据**。
所有"它知道你在干什么"的效果，都只来自你浏览器本地的时间、滚动位置和访问次数。
一切只发生在屏幕里。

## 🛠 技术

单文件、零依赖、可离线运行：

- HTML + CSS + 原生 JavaScript（`index.html`，约 70 KB）
- 滚动进度驱动的全局色彩 / 噪点 / 文字腐化系统
- Web Audio API 实时合成音效（低频嗡鸣、心跳、尖啸，无音频文件）
- SVG 程序化绘制的"它"

直接双击 `index.html` 即可游玩，或部署到任意静态托管（如 GitHub Pages）。
